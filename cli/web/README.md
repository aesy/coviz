# coviz report UI

The frontend for the HTML coverage report, built with Vite + Preact + TypeScript
and CSS Modules. It compiles to a single self-contained file that the Rust binary
embeds and fills with per-run data.

## Commands

- `npm run dev` - live dev server with HMR. The real data isn't available here, so
  it renders `src/sample.ts` (a fixture that never ships in the build).
- `npm run build` - bundles and inlines everything into one HTML file, then copies
  it to `../assets/report.html`. Run this after any change under `src/`.

## How data gets in

`index.html` carries two template tokens the bundler leaves untouched:
`[[= title =]]` in the `<title>` and `[[= data =]]` in a JSON `<script>`. At report
time the Rust side renders them with minijinja (see `src/output/html.rs`). The
custom `[[= ... =]]` delimiters avoid colliding with `{{ }}` that can appear in
minified JS.

## Layout

- `src/lib/` - types, formatting helpers, theme and hash-routing hooks.
- `src/components/` - one component + `.module.css` per UI area.
- `src/global.css` - design tokens, theme, and shared atoms (color buckets,
  meters, dots, buttons).

**Do not edit `../assets/report.html` by hand** - it is generated by `npm run build`.
